# 🚀 Portofolio Raflitya

Aplikasi web portofolio interaktif yang dibangun dengan **React** (frontend) dan **Node.js + Express** (backend REST API).

## 📁 Struktur Proyek

```
PrakWeb2026_C_243040095/
├── praktikum-react-modul1/
```
